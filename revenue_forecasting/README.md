# Revenue Forecasting

This project focuses on revenue forecasting using real-world public financial and macroeconomic data.

## Project Goals

- Build strong forecasting baselines
- Compare time series and machine learning models
- Perform statistical testing and scenario analysis
- Expose results through clean notebooks, reusable pipelines, and deployment-ready structure

## Project Structure

- `config/` configuration files
- `data/` raw, processed, features, predictions
- `entrypoint/` train and inference scripts
- `notebooks/` analysis notebooks
- `src/pipelines/` reusable pipeline code
- `app/` API files
- `tests/` automated tests
- `models/` saved model artifacts
- `reports/` charts and outputs
